# Evidence selection source supplement v1

Twenty naturally phrased authored engineering questions (16 answerable, four
unsupported) in English, Polish and German. This is a source-grounded supplement,
not a blind human annotation study or a sample of private production knowledge.
Labels and corpus hashes were frozen before retrieval/scoring. The selector was
not tuned after seeing results. See `FREEZE.json` and `dataset.json` for exact
passages, scope labels, languages and public source URLs.

Public documentation notes paraphrase SQLite WAL, PostgreSQL isolation, Git revert
and CMake generated-file dependencies. Atlas and the R6/R7 release procedures are
explicitly fictional. They cover long multi-section prerequisites/acceptance,
cross-language retrieval, conflicting superseded material, same-document evidence,
multi-document and hybrid-scope questions. No unsupported question has invented
positive evidence. Similar release text is a distractor, not a current source.

The database comparison connects WAL and PostgreSQL topics, so questions are not
independent observations. Related translations/procedure questions also share
sources. Synthetic distractors generated by the separate scalability phase must
not be counted as independent relevance judgments.

`tools/evidence_selection/build_fixture.py` documents reproducible construction
and refuses to overwrite an existing frozen directory. No production source is
read. Run evaluations only through `scripts/run_isolated.py`.
