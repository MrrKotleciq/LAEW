# Fictional sensor calibration procedure C7
## Preconditions and reference points
These requirements define an invented engineering fixture, not a real manufacturer's procedure. C7 calibration starts only after the chamber temperature has been stable for 90 seconds. Acquire reference readings at minus 10, zero and plus 10 units. Keep the device orientation unchanged while collecting those reference points. A single reference value is insufficient for the C7 release record even when its residual happens to be small.
## Acceptance and audit record
The maximum absolute residual at each reference point is 0.4 units. A passing mean residual cannot compensate for one failing reference point. The release record must contain the coefficient digest and the chamber temperature. The digest is an identity check for the actual coefficient set used during the test; the record is not complete if it contains only an informal calibration date. Temperature stabilization and acceptance limits are separate conditions that must both be satisfied.
## Version applicability
This document applies to procedure C7. The archived C6 procedure has different waiting time and acceptance limits. Its overlap in terminology is intentional: migration documentation can be retrieved alongside the active procedure, but the version named by the question determines which evidence is applicable.
