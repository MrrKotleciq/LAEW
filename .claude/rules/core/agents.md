# Agent Use 
Use available sub-agents when they provide clear value. 
- Use a planning/architecture agent for complex features, refactors, or architectural decisions. 
- Use a testing/TDD agent for non-trivial new behavior or bug fixes. 
- Use a code-review agent after meaningful code changes. 
- Use a security-focused agent for security-sensitive changes. 
- Run independent analyses in parallel when practical. 
- Do not delegate work that fits cleanly in the current context. 
- When delegating, collect and integrate all results before completing the task. 
- Treat the final integrated result as the deliverable.
