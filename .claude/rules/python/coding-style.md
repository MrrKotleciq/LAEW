# Python Coding Style

Follow the project's configured Python tooling and conventions.

- Follow PEP 8 and existing project style.
- Use type annotations on public functions and meaningful internal interfaces.
- Prefer clear, idiomatic Python over unnecessary abstraction.
- Prefer immutable values when practical.
- Use `ruff`, `black`, and the project's configured type checker consistently.
- Follow existing package and import conventions.
