# LAEW Architecture Review

## Purpose

Analyze architectural decisions and proposed changes in LAEW.

## Procedure

1. Read the relevant architecture documentation.
2. Inspect the current implementation if relevant.
3. Identify the existing architectural decision.
4. Identify the proposed change.
5. Compare alternatives.
6. Identify trade-offs.
7. Identify compatibility issues.
8. Determine whether an ADR should be updated or created.

## Output

Provide:

- Current architecture
- Proposed change
- Motivation
- Alternatives
- Trade-offs
- Risks
- Recommendation
- Required documentation changes

Do not modify files unless explicitly requested.
