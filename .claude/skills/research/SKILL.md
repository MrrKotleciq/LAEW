# LAEW Research

## Purpose

Perform technical research for LAEW engineering decisions.

## Procedure

1. Define the research question.
2. Identify what is already known from project documentation.
3. Identify missing information.
4. Research external sources when required.
5. Prefer primary and authoritative sources.
6. Separate sourced facts from inference.
7. Compare relevant alternatives.
8. State uncertainty.
9. Produce a recommendation only after presenting the evidence.

## Output

Use:

- Question
- Existing project context
- Evidence
- Alternatives
- Comparison
- Risks
- Recommendation
- Sources

Do not modify project files during research unless explicitly
requested.
