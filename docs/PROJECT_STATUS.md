## Important distinction

The architecture documentation describes the intended
LAEW v1.0 system.

The current repository does NOT yet implement every
architectural component.

Future implementation must be evaluated against the
documented architecture.

## Current migration

Antigravity/Gemini is being introduced as an external
engineering agent.

The agent must not be treated as the LAEW runtime itself.

The project remains model-agnostic.

## Immediate objective

Establish a controlled development workflow in which
Antigravity can understand the LAEW repository and its
architecture without replacing the project's design
with assumptions generated by the model.
